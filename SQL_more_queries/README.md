# SQL - More Queries

## Description

This project is part of the Holberton School Higher Level Programming curriculum.

The objective is to practice advanced SQL concepts using MySQL 8.0, including user management, permissions, constraints, joins, subqueries, unions, and relational database design.

## Learning Objectives

By completing this project, I learned how to:

- Create MySQL users
- Grant and manage privileges
- Use PRIMARY KEY and FOREIGN KEY
- Apply NOT NULL and UNIQUE constraints
- Query data from multiple tables
- Write INNER, LEFT and RIGHT JOIN queries
- Use subqueries
- Combine results using UNION
- Follow SQL style guidelines

## Requirements

- Ubuntu 20.04 LTS
- MySQL 8.0.25
- SQL keywords written in uppercase
- Every SQL file starts with a task description comment
- Every query has a comment before it
- All files end with a new line

Run a SQL script with:

```bash
cat filename.sql | mysql -uroot -p
```

