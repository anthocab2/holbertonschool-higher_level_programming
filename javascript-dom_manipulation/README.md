# JavaScript DOM Manipulation

## Description

This project introduces DOM (Document Object Model) manipulation using JavaScript.

Students learn how to select HTML elements, modify their content and styles, handle user events, and make HTTP requests without reloading the page.

## Learning Objectives

At the end of this project, you should be able to explain:

- What JavaScript is
- How to select HTML elements
- Difference between ID, class and tag selectors
- How to modify HTML elements
- How to manipulate the DOM
- How to listen to events
- How to make HTTP requests using XMLHttpRequest and Fetch API

## Requirements

- Chrome browser 57 or later
- All files end with a new line
- Code must be Semistandard compliant
- Do not use `var`
- HTML must not reload after DOM manipulation
