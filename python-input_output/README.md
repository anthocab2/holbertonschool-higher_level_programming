# Python - Input/Output

This project focuses on file handling, JSON serialization, deserialization, and command line arguments in Python.

## Learning Objectives

- Open a file in Python
- Read the full content of a file
- Read a file line by line
- Write text to a file
- Use the `with` statement
- Understand JSON
- Convert Python objects to JSON strings
- Convert JSON strings to Python objects
- Access command line arguments with `sys`

## Requirements

- Ubuntu 20.04 LTS
- Python 3.8.5
- pycodestyle 2.7.*
- All files must be executable
- All files must start with `#!/usr/bin/python3`
- All files must end with a new line
- No extra imports unless allowed by the task
