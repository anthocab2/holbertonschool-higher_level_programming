# Python - Data Structures: Lists & Tuples

## Description
This project is part of the curriculum of :contentReference[oaicite:0]{index=0}.

The main goal is to learn how to work with:
- Lists
- Tuples
- Sequences
- List methods
- List comprehensions
- Sequence unpacking
- Stack and queue behaviors in Python

---

## Learning Objectives

At the end of this project, I should be able to explain:

- What lists are and how to use them
- Differences between strings and lists
- Common list methods
- How to use lists as stacks and queues
- What tuples are and when to use them
- What sequences are
- Tuple packing and unpacking
- How to use the `del` statement
