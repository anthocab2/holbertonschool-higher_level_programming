# Python - Abstract Base Classes

## Description

This project focuses on Abstract Base Classes (ABCs) in Python.  
Abstract classes allow developers to define a common structure that subclasses must follow.

In this project, we practice how to create an abstract class using Python's `abc` module and how to implement required methods in child classes.

## Learning Objectives

By the end of this project, I should be able to explain:

- What an Abstract Base Class is
- How to use the `ABC` class from the `abc` module
- How to define abstract methods with `@abstractmethod`
- How subclasses implement methods from an abstract class
- Why abstraction is useful in object-oriented programming
