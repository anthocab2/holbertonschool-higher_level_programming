# JavaScript - Warm Up

## Description

This project introduces the fundamentals of JavaScript through scripting exercises. It covers the basic syntax of the language, variables, data types, operators, conditions, loops, functions, objects, and modules while following the Holberton School coding standards.

The scripts are executed with **Node.js 14.x** on **Ubuntu 20.04 LTS** and must comply with **semistandard** style.

---

## Learning Objectives

By the end of this project, I should be able to explain:

* Why JavaScript is amazing
* How to run JavaScript scripts with Node.js
* How to declare variables and constants
* The differences between `var`, `let`, and `const`
* JavaScript data types
* Conditional statements (`if`, `if...else`)
* Loops (`while` and `for`)
* Functions and return values
* Variable scope
* Arithmetic operators
* Objects and arrays
* How to import files (modules)

---

## Requirements

* Ubuntu 20.04 LTS
* Node.js 14.x
* semistandard 16.x.x
* All files start with:

```javascript
#!/usr/bin/node
```

* All files are executable.
* All files end with a new line.
* Code follows semistandard style.

## Usage

Give execution permission:

```bash
chmod +x 0-javascript_is_amazing.js
```

Run the script:

```bash
./0-javascript_is_amazing.js
```

Or:

```bash
node 0-javascript_is_amazing.js
```

Check code style:

```bash
semistandard *.js
```
