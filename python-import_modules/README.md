# Python - Import & Modules

## Description
This project is part of the curriculum of :contentReference[oaicite:0]{index=0}.

The goal of this project is to learn how to:
- Import functions from another file
- Create and use Python modules
- Use command line arguments
- Prevent code execution when importing files
- Work with Python built-in functions like `dir()`
- Follow Python coding style using `pycodestyle`
