# Python - If/Else, Loops, Functions

This project introduces control flow tools in Python.

## Description

The goal of this project is to practice conditional statements, loops, functions, variables, indentation, comments, arithmetic operators, and Python coding style.

## Learning Objectives

By the end of this project, I should be able to explain:

- Why indentation is important in Python
- How to use `if`, `if...else`, and `elif`
- How to use comments
- How to assign values to variables
- How to use `while` and `for` loops
- How to use `break` and `continue`
- How to use `else` clauses on loops
- How to use `pass`
- How to use `range`
- What a function is
- How to use functions
- What a traceback is
- How to use arithmetic operators

## Requirements

- Ubuntu 20.04 LTS
- Python 3.8.*
- pycodestyle 2.7.*
- Allowed editors: vi, vim, emacs
- All Python files must start with `#!/usr/bin/python3`
- All Python files must be executable
- All files must end with a new line
