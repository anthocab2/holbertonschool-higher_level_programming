# Python - Exceptions

## Description

This project introduces exception handling in Python.

The goal is to understand the difference between errors and exceptions, how to catch exceptions, when to raise them, and how to write safer Python programs.

## Learning Objectives

* Understand errors and exceptions
* Use try and except blocks
* Handle exceptions correctly
* Raise built-in exceptions
* Perform cleanup actions after exceptions
* Write robust Python code

## Requirements

* Ubuntu 20.04 LTS
* Python 3.8.5
* pycodestyle 2.7.*
* All files executable
* First line:

  ```python
  #!/usr/bin/python3
  ```

## Files

| File                 | Description                                               |
| -------------------- | --------------------------------------------------------- |
