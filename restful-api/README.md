# RESTful API

## Description

This project focuses on understanding, consuming, developing, securing, and documenting RESTful APIs using Python.

RESTful APIs allow different systems to communicate through HTTP methods such as GET, POST, PUT, and DELETE. In this project, the main goal is to practice API concepts from the basics of HTTP/HTTPS to consuming public APIs, processing JSON data, exporting data to CSV, and building APIs using Python tools and frameworks.

## Learning Objectives

By the end of this project, I should be able to:

- Explain the difference between HTTP and HTTPS
- Understand the structure of HTTP requests and responses
- Identify common HTTP methods and status codes
- Consume APIs using command-line tools
- Consume APIs using Python
- Use the `requests` library to send HTTP requests
- Parse and manipulate JSON data
- Convert structured data into CSV format
- Understand the basics of API development
- Understand API security and authentication
- Understand the importance of API documentation with OpenAPI
