# Python - Inheritance

## Description

This project focuses on inheritance in Python. It covers how classes can inherit attributes and methods from other classes, how to inspect objects, and how to use built-in functions related to object-oriented programming.

## Learning Objectives

- Understand what a superclass, base class, or parent class is
- Understand what a subclass is
- List all attributes and methods of a class or instance
- Know when an instance can have new attributes
- Inherit a class from another class
- Define a class with multiple base classes
- Understand the default class every class inherits from
- Override methods or attributes inherited from a base class
- Use `isinstance`, `issubclass`, `type`, and `super`
